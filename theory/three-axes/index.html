สามแกนของสี

ทุกสีบอกได้ด้วยค่าสามค่า หรือที่เรียกกันว่าสามแกน คือ เนื้อสี ความสด และความสว่าง รู้ว่าแกนไหนทำอะไร ก็เลิกสุ่มสีได้

01

ทำไมต้องรู้เรื่องนี้

งานจริงที่เจอบ่อยที่สุดของเรื่องนี้คือ ปุ่มหนึ่งปุ่มต้องมีห้าหน้าตา — ปกติ ชี้ค้าง กดอยู่ ปิดใช้งาน และตอนโฟกัสด้วยคีย์บอร์ด

ถ้าไม่รู้ว่าขยับแกนไหน

ก็จะเปิดตัวเลือกสีขึ้นมาสุ่มหยิบสีใหม่ทีละสถานะ สุดท้ายได้ห้าสีที่ดูไม่เข้าพวก และพอวันหนึ่งแบรนด์เปลี่ยนสีหลัก ต้องมานั่งสุ่มใหม่ทั้งห้าสถานะ

ถ้ารู้

ทั้งห้าสถานะมาจากสีเดียวโดยขยับแค่ความสว่างทีละขั้น เปลี่ยนสีแบรนด์เมื่อไร อีกสี่สถานะก็เลื่อนตามเองทั้งชุด

03

Tint / Shade / Tone จากสีตั้งต้นของคุณเอง

สามคำที่อยู่ในภาพข้างบนไม่ใช่ศัพท์เฉพาะทางศิลปะที่เอามาใช้ไม่ได้ — มันคือสูตรตรง ๆ ว่าจะขยับแกนไหนกี่เปอร์เซ็นต์ ใส่สีตั้งต้นแล้วดูผลได้เลย

สร้างชุดสีจากสีเดียว เปลี่ยนสีตั้งต้นได้
#4F46E5

Tint เพิ่มความสว่างทีละ 12% · Shade ลดความสว่างทีละ 10% · Tone ลดความสดทีละ 20% โดยไม่แตะความสว่าง

แถว Tone คือแถวที่คนมองข้ามบ่อยที่สุด เวลาสีดูแสบตาเกินไป คนส่วนใหญ่จะลดความสว่าง ซึ่งทำให้สีทึบลงแต่ยังแสบอยู่ ทั้งที่สิ่งที่ควรลดคือความสด

04

ข้อผิดที่เจอบ่อย

  • ขยับสองแกนพร้อมกันแล้วคุมผลไม่ได้ ลากตัวเลือกสีแบบสองมิติคือการขยับความสดกับความสว่างพร้อมกัน ถ้าต้องการผลที่เดาได้ ให้ขยับทีละแกน
  • คิดว่า Lightness เท่ากันแปลว่าสว่างเท่ากัน HSL ที่ L 52% ให้คอนทราสต์ตั้งแต่ 1.64 ถึง 6.19 ขึ้นกับเนื้อสี เรื่องนี้อยู่ในตอนที่ 03
  • ทำ hover ด้วยการลด opacity พอโปร่งใสลง สีจะผสมกับพื้นข้างหลัง ปุ่มเดียวกันบนพื้นคนละสีจะได้ผลคนละแบบ และคอนทราสต์ตกโดยไม่รู้ตัว
  • ใช้ความสด 100% กับพื้นที่กว้าง ขอบสีจะดูสั่นและตาล้าเร็ว พื้นที่กว้างใช้ความสด 10–30% แล้วเก็บสีสดไว้กับชิ้นเล็ก
05

สรุปและแหล่งอ้างอิง

สรุปสามข้อ

  • เนื้อสีเปลี่ยนว่าเป็นสีอะไร ความสดเปลี่ยนอารมณ์ ความสว่างเปลี่ยนว่าใช้งานได้จริงหรือไม่
  • Tint / Shade / Tone คือการขยับแกนเดิม ไม่ใช่การหาสีใหม่
  • ขยับทีละแกนแล้วผลลัพธ์จะเดาได้ ซึ่งเป็นสิ่งที่ระบบสีต้องการ

อ่านต่อจากต้นทาง

  • MDN · hsl()ไวยากรณ์ HSL ใน CSS และช่วงค่าที่รองรับ
  • MDN · CSS color valuesภาพรวมของทุกวิธีเขียนสีใน CSS
