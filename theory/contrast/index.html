ตอนที่ 08 · การเข้าถึง

Contrast และเกณฑ์ WCAG

เรื่องนี้เป็นส่วนเดียวของทฤษฎีสีที่มีผิดมีถูกชัดเจน เพราะวัดออกมาเป็นตัวเลขได้ ค่าอยู่ระหว่าง 1:1 ถึง 21:1 และมีเส้นขั้นต่ำที่ห้ามต่ำกว่า

01

ทำไมต้องรู้เรื่องนี้

เรื่องนี้ต่างจากทุกเรื่องในคอร์สตรงที่มันไม่ใช่ความเห็น — ถ้าไม่ผ่านคือไม่ผ่าน และในหลายประเทศมันเป็นข้อกำหนดทางกฎหมายสำหรับบริการสาธารณะ

สิ่งที่มักเกิดขึ้น

งานผ่านรีวิวดีไซน์สวยงาม แล้วไปตกตอน accessibility audit ก่อนขึ้นระบบ ต้องกลับมาแก้สีทั้งระบบในสัปดาห์สุดท้าย

ทางที่ควรเป็น

ล็อกค่าขั้นต่ำไว้ตั้งแต่ตอนวาง token แล้วทุกอย่างที่สร้างจาก token นั้นจะผ่านโดยอัตโนมัติ เหลือแค่กรณีพิเศษไม่กี่จุดที่ต้องตรวจมือ

    คอนทราสต์คืออัตราส่วนความสว่างของสองสี ไม่ใช่ความต่างของเนื้อสี สีคู่ตรงข้ามที่สดทั้งคู่จึงได้ค่าต่ำมากได้ ทั้งที่มองแล้วเหมือนอยู่คนละขั้วกันเลย (ย้อนไปลากดูได้ที่ตัวอย่างขอบสีสั่นในตอนที่ 04)

    03

    ตัวเลขนี้คำนวณมาจากอะไร

    คอนทราสต์ตาม WCAG ไม่ได้วัดจากความต่างของค่า RGB ตรง ๆ แต่คำนวณผ่าน “ความสว่างสัมพัทธ์” (relative luminance) ซึ่งให้น้ำหนักสีเขียวมากที่สุด เพราะตาคนไวต่อเขียวที่สุด

    ข้อยกเว้นที่คนมักไม่รู้ มีสามข้อ

    • องค์ประกอบที่ปิดใช้งาน ไม่ต้องผ่านเกณฑ์ แต่ยังต้องบอกให้รู้ว่าปิดอยู่ด้วยวิธีอื่น
    • โลโก้และชื่อแบรนด์ ได้รับการยกเว้นตามสเปก
    • ตัวหนังสือที่เป็นส่วนหนึ่งของภาพประกอบ เช่น ป้ายในรูปถ่าย ไม่ถูกนับ

    ทั้งสามข้อเป็นข้อยกเว้นทางเทคนิค ไม่ใช่ใบอนุญาตให้ทำให้อ่านไม่ออก

    04

    ข้อผิดที่เจอบ่อย

    • ตรวจเฉพาะข้อความ ลืมองค์ประกอบอื่น เส้นขอบช่องกรอก ไอคอน วงแหวนโฟกัส และแท่งกราฟ ล้วนอยู่ใต้เกณฑ์ 3:1 ของ SC 1.4.11
    • ใช้สีเทาอ่อนกับ placeholder placeholder คือข้อความที่ผู้ใช้ต้องอ่านตอนยังไม่รู้ว่าต้องกรอกอะไร จึงยิ่งต้องอ่านออก
    • วัดคอนทราสต์บนพื้นที่ไม่ใช่พื้นจริง ถ้าปุ่มลอยอยู่บนภาพ ต้องวัดกับสีที่อยู่ใต้ปุ่มจริง ๆ ไม่ใช่กับสีพื้นของหน้า
    • คิดว่าธีมมืดผ่านอัตโนมัติ ต้องวัดใหม่ทั้งชุด สีแบรนด์ที่ผ่านบนพื้นขาวมักตกทันทีเมื่อไปอยู่บนพื้นเข้ม
    05

    สรุปและแหล่งอ้างอิง

    สรุปสามข้อ

    • คอนทราสต์เป็นอัตราส่วนของความสว่าง ไม่ใช่ความต่างของเนื้อสี
    • เกณฑ์มีสองกลุ่ม — ข้อความตาม SC 1.4.3 และองค์ประกอบอื่นตาม SC 1.4.11
    • ล็อกค่าขั้นต่ำไว้ใน token ตั้งแต่ต้น จะไม่ต้องไล่แก้ทีหลัง

    อ่านต่อจากต้นทาง

    • WCAG 2.2 · SC 1.4.3 Contrast (Minimum)เกณฑ์ของข้อความ พร้อมนิยามของ “ข้อความตัวใหญ่”
    • WCAG 2.2 · SC 1.4.11 Non-text Contrastเกณฑ์ 3:1 ของไอคอน เส้นขอบ และตัวชี้โฟกัส
    • WebAIM Contrast Checkerเครื่องมือภายนอกสำหรับตรวจซ้ำ
    ตอนก่อนหน้าจากสีเดียวสู่สเกล 11 ขั้น ตอนถัดไปDark Mode ที่ทำถูกวิธี
