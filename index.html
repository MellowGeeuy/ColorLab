ทฤษฎีสีสำหรับงานอินเทอร์เฟซ

สิบเอ็ดตอน แยกกันคนละหน้า อ่านเรียงหรือเลือกเฉพาะเรื่องที่ต้องใช้ก็ได้ ทุกตอนมีตัวอย่างที่กดเล่นได้ ค่าสีที่วัดจริง ข้อผิดที่เจอบ่อย และเช็กลิสต์ก่อนส่งงาน

เริ่มอ่านตอนแรก ข้ามไปสร้างชุดสีเลย

พื้นฐาน

01 สีทำงานก่อนตัวหนังสือ ทำไมสายตาถึงอ่านสีก่อนอ่านคำ และทำไมสีถึงห้ามเป็นช่องทางเดียวที่บอกความหมาย พื้นฐาน · อ่าน ~6 นาที 02 สามแกนของสี เนื้อสี ความสด ความสว่าง — สามค่าที่อธิบายทุกสีได้ และแกนไหนตัดสินว่างานใช้ได้จริง พื้นฐาน · อ่าน ~7 นาที 03 Color Models เลือกให้ถูกงาน HEX RGB HSL OKLCH ต่างกันตรงไหน และทำไมความสว่างของ HSL ถึงเชื่อไม่ได้ พื้นฐาน · อ่าน ~7 นาที

ทฤษฎีสี

04 วงล้อสีและชุดสีที่เข้ากัน สูตร harmony เจ็ดแบบบนวงล้อ ใช้กับงานจริงอย่างไร และทำไมสูตรถึงไม่การันตีว่าอ่านออก ทฤษฎีสี · อ่าน ~8 นาที 05 สีกับความรู้สึก ความหมายของสีมาจากบริบทและวัฒนธรรม ไม่ใช่กฎสากล พร้อมตารางเทียบรายภูมิภาค ทฤษฎีสี · อ่าน ~6 นาที

ระบบสีใน UI

06 สี่บทบาทของสีในหน้าจอเดียว Primary Neutral Semantic Accent — วิธีแบ่งบทบาทและตั้งชื่อ token ให้แก้ที่เดียวจบ ระบบสีใน UI · อ่าน ~7 นาที 07 จากสีเดียวสู่สเกล 11 ขั้น ทำไมต้องมี 11 ขั้น ขั้นไหนใช้กับอะไร และวิธีแมปสเกลเข้ากับสถานะของคอมโพเนนต์ ระบบสีใน UI · อ่าน ~7 นาที

การเข้าถึง

08 Contrast และเกณฑ์ WCAG เกณฑ์คอนทราสต์ของ WCAG 2.2 ทั้งข้อความและองค์ประกอบที่ไม่ใช่ข้อความ พร้อมเครื่องวัดในหน้า การเข้าถึง · อ่าน ~9 นาที 09 Dark Mode ที่ทำถูกวิธี ธีมมืดไม่ใช่การกลับสี แต่คือการออกแบบชุดสีใหม่ที่มีกฎเรื่องความสูงและความสดของตัวเอง การเข้าถึง · อ่าน ~7 นาที

ลงมือใช้จริง

10 สัดส่วนการใช้สี กฎ 60/30/10 ในงาน UI จริง พร้อมเครื่องมือวัดสัดส่วนพื้นที่ของหน้าจอตัวอย่าง ลงมือใช้จริง · อ่าน ~6 นาที 11 ก่อนแก้ / หลังแก้ สี่ปัญหาที่เจอบ่อยที่สุดเวลารีวิวงาน พร้อมวิธีตรวจงานตัวเองห้าขั้นก่อนส่ง ลงมือใช้จริง · อ่าน ~6 นาที
